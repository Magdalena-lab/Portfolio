My Portfolio Website – Showcase of my projects and skills.

**Description**

This repository contains my personal portfolio website. It presents my projects, skills, and experience in a structured, case-study format.

The website is designed to be simple and clear, with focus on presenting information in an understandable way. Currently, it includes one project, with more planned.

Structure
 - Built using HTML and CSS
 - Static website hosted via GitHub Pages
 - Organized in a way that allows easy updates and adding new projects

The structure supports gradual development of the portfolio without the need for complex setup.

**Development Approach**

I created the main website myself. During the process, I used AI mainly to learn HTML and CSS and to understand how specific changes in the code affect the visual outcome of the website.

All design decisions, layout, and organization of content were defined and implemented by me.

**Contact Page**

The Contact subpage was added later and created fully with the help of AI (Claude).

I provided instructions regarding:

 - matching the existing design and layout
 - connecting the page with my HubSpot form
 - integrating it into the current website structure

Based on these requirements, the page was generated and implemented.

This approach allowed me to save time on implementation while keeping consistency with the rest of the website.

**Live Website**

https://magdalena-lab.github.io/Portfolio/

The website can be accessed directly through the browser. No installation is required.
